# Guía rápida para agregar evidencias

## ¿Dónde colocar cada imagen?

La carpeta depende de la actividad:

- `actividad-1.html` → carpeta `img1`
- `actividad-2.html` → carpeta `img2`

Ejemplo para la semana 08:

```text
actividades/semana-08/img1/evidencia-1.webp
actividades/semana-08/img1/evidencia-2.webp
actividades/semana-08/img2/evidencia-1.webp
actividades/semana-08/img2/evidencia-2.webp
```

Si las carpetas `img1` o `img2` todavía no existen, créalas dentro de la carpeta de la semana.

## Reglas para los nombres

Usa esta secuencia:

```text
evidencia-1.webp
evidencia-2.webp
evidencia-3.webp
```

También funcionan `.png`, `.jpg` y `.jpeg`. No uses espacios ni cambies la numeración.

## Publicar los cambios en GitHub

Después de copiar las imágenes:

1. Guarda los archivos dentro de la carpeta del proyecto.
2. Súbelos al mismo repositorio de GitHub.
3. Espera unos segundos a que GitHub Pages publique la actualización.
4. Abre la semana y la actividad correspondiente para verificar la galería.

GitHub no guarda carpetas vacías. Por eso, `img1` o `img2` aparecerán en el repositorio cuando agregues al menos una imagen.
